# Connecting Objects

Connect objects by dragging from one object's handle to another object's handle.

<video src="/content/videos/standard-connect.webm" autoplay loop muted playsinline></video>

Handles are gray, blue, orange, or purple circles at the top or bottom of objects.

- The starting handle highlights while you connect it.
- Patchies dims invalid connection targets.

## Easy Connect

Use the _easy connect_ button in these cases:

1. You use a touch device, such as a phone or tablet.
2. You cannot find the small object handles or drag to them.
3. You want to connect many handles by tapping or clicking.

<video src="/content/videos/easy-connect.webm" autoplay loop muted playsinline></video>

Easy Connect makes handles larger for touch input.

To use Easy Connect:

1. Find the cable button in the toolbar. This button enables _easy connect_.
2. Tap a large handle to start a connection.
3. Patchies highlights the starting handle and dims invalid targets.
4. Tap another large handle to connect the two handles.
5. Repeat these steps to make more connections.
6. Click the _easy connect_ button again to stop.
