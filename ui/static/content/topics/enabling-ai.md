# Enabling AI

AI features help you create and change patches. You choose whether to enable them.

## AI Is Optional

Patchies does not enable AI features by default. Enable them explicitly when you want to use them.

Patchies hides or disables AI features until an API key is present. To change feature visibility, use one of these options:

- In **Settings** (`Cmd/Ctrl + ,`), select **AI → Show AI features**.
- In the command palette (`Cmd/Ctrl + K`), select `Toggle AI Features`.

## Protect Your API Key

Patchies stores API keys in your browser. Patchies does not manage or access your keys.

Malicious patches that you open can steal your API key. Use a separate API key with strict budget limits.

Do not open patches from strangers when an API key is set.

## Features using AI

These features use AI with your patch:

- [Edits](/docs/ai-edits) — Create and edit objects with natural language.
- [Chat](/docs/ai-chat) — Ask an AI assistant about your patch.
- [Patch to App](/docs/ai-patch-to-app) — Convert a patch into a standalone HTML app.

## Objects using AI

These objects use AI to generate patch content:

- [ai.tts](/docs/objects/ai.tts) — Create speech from text.
- [ai.stt](/docs/objects/ai.stt) — Create text from speech.
- [ai.txt](/docs/objects/ai.txt) — Generate text.
- [ai.img](/docs/objects/ai.img) — Generate images.
- [ai.music](/docs/objects/ai.music) — Generate music.

Consider copyright and ethics when you generate AI content. This is especially important for public or commercial projects.
